## Store listing tab

**Name** (from the manifest): `Volet`

**Summary** (the manifest's `description`, at most 132 characters, set in `wxt.config.ts`):

```
Vertical tabs in Chrome's side panel: switch between workspaces (Volets), each with its own pinned tabs, folders and colors.
```

**Category**: Productivity, Workflow & Planning. **Language**: English.

**Description**:

```
Volet puts your tabs in a vertical list in Chrome's side panel, and sorts them into workspaces called Volets: one for work, one for a trip, one for a side project. Switch Volets and the sidebar shows only that Volet's tabs, tinted in its color.

VOLETS
• Each Volet has its own pinned tabs, folders and everyday tabs, and its own color.
• Switch with the shutters at the bottom of the sidebar, a two-finger swipe, the search palette, or a keyboard shortcut.
• Each window shows its own Volet. In Chrome's tab strip, every Volet is a tab group, and the others are collapsed out of the way.

PINNED TABS AND FOLDERS
• Pins keep their page: wander off and the row shows where you are, with a button to go back.
• Close a pin's tab and the pin stays, ready for next time. Unpin it in one click.
• Folders nest, and a collapsed folder still shows the tabs open inside it.

FAVORITES
• A grid of your most used sites at the top, shared by every Volet.

EVERYDAY TABS
• New tabs land below the pins. "Clear" closes them all at once.
• Tabs you haven't used for 12 hours are archived (you choose how long, or never), and search finds them again.

DRAG AND DROP
• Drag tabs to reorder them, pin or unpin them, file them into folders or favorites, or move them to another Volet: hold one over a Volet's shutter to switch to it and drop it right where you want.
• Nothing jumps around while you drag: a line shows where the tab will land.
• Select several rows with Shift-click or Cmd/Ctrl-click and drag them together.

SEARCH PALETTE
• Press Ctrl+M (Control+M on a Mac too) on any page to search your open tabs in every window, your pins, favorites, archived tabs and Volets, open a web address, or search the web.

RECENT TAB SWITCHER
• Hold Ctrl (Control on a Mac too) and press Q to see your five most recent tabs in this window, with a preview of each, across Volets. Let go to switch: a quick tap goes back to the tab you last used, like Cmd+Tab.
• Add Shift to go the other way. The arrow keys move the selection, Escape cancels, and you can close a tab right from the switcher.

RIGHT-CLICK MENUS
• Rename, move to another Volet, put in a new folder, change a Volet's color, and more, on every tab, pin, folder, favorite and Volet.

COMING FROM ARC?
• Import your Arc Spaces, with their colors, pinned tabs, folders and favorites. Volet reads Arc's sidebar file in your browser; the file never leaves your computer.

YOUR DATA STAYS YOURS
• Your Volets, pins, folders and favorites live in your Chrome bookmarks, in a folder named "Volet", so they follow you to your other computers with Chrome Sync and survive a reinstall.
• Volet has no server, no account and no analytics. Nothing you do is sent anywhere.

KEYBOARD SHORTCUTS
• Ctrl+B: show or hide the sidebar
• Ctrl+M: search
• Ctrl+Q: cycle through your recent tabs, hold Ctrl to pick one (Ctrl+Shift+Q in reverse)
• On a Mac, these use the Control key too
• Next and previous Volet, pin or unpin the current tab, copy its link: set your own in chrome://extensions/shortcuts

GOOD TO KNOW
• Chrome's own tab strip stays at the top; Volet keeps it tidy by collapsing the other Volets' groups.
• Chrome decides the side panel's width and side.

Volet is free and open source (GPL-3.0): https://github.com/pierregoutheraud/volet
```

## Privacy tab

**Single purpose description**:

```
Volet organizes the browser's tabs into workspaces (Volets) shown as vertical tabs in Chrome's side panel: each Volet holds its own pinned tabs, folders and open tabs, and the user switches between them.
```

**Permission justifications**:

`sidePanel`

```
Volet's whole interface is the sidebar shown in Chrome's side panel, opened from the toolbar icon or a shortcut.
```

`tabs`

```
The sidebar lists the window's tabs with their titles, addresses and icons, and lets the user open, switch to, move, close and archive them. Search also finds open tabs in every window.
```

`tabGroups`

```
Each Volet (workspace) is a Chrome tab group: Volet creates, names, colors and collapses these groups so the tab strip matches the sidebar.
```

`bookmarks`

```
Volets, pinned tabs, folders and favorites are stored as bookmarks in a "Volet" folder, so they sync with the user's bookmarks and survive a reinstall.
```

`storage`

```
Stores settings, Volet colors, which folders are open, archived tabs, and which tab belongs to which pin, all in the extension's own storage.
```

`alarms`

```
A check every 5 minutes closes everyday tabs the user hasn't used for the time chosen in settings (12 hours by default) and keeps them in a searchable archive.
```

`favicon`

```
Shows each site's icon next to its tab, pin, favorite and search result, from Chrome's own favicon cache.
```

`search`

```
The search palette's "Search for..." result runs the query with the user's default search engine, in a new tab.
```

`activeTab`

```
When the user presses the search shortcut, the search palette opens over the page they are on. When the user presses the copy shortcut, the page they are on copies its own link to the clipboard and says so. activeTab keeps both working on the current tab, only after the user's shortcut, when the user has withheld Volet's website access in Chrome.
```

`scripting`

```
Injects the search palette into the current page when the user presses its shortcut or the search button in Volet's side panel, and a small script that copies the page's link when the user presses the copy shortcut. Registers the recent tab switcher's small listener on websites (in their frames too, where the keyboard focus may be) for its shortcut's modifier being released, and adds the switcher's overlay to a page the first time the user presses its shortcut there. All scripts are part of the extension package; no remote code.
```

**Host permissions**: `<all_urls>`, for the recent tab switcher (on by default; removing both of its shortcuts turns it off) and for the search palette opened from the side panel. Chrome shows
it at install ("Read and change all your data on all websites") and puts the item through a closer review.

```
The recent tab switcher (on by default; removing both of its shortcuts turns it off) needs website access for three things. Chrome's keyboard commands only report the shortcut being pressed, so a packaged content script listens on websites for its modifier being released, which picks the tab. The same script draws the centered switcher over the page. And Volet captures a preview of the visible page as tabs are visited. Previews are small images kept in memory on the device (ten at most), are never synced or uploaded, are shown in a closed shadow root that websites can't read, and incognito pages are not captured. Website access also lets the search palette opened from Volet's side panel show over the current page, as a click in the side panel doesn't grant activeTab.
```

(The manifest also makes `_favicon/*` web accessible so the in-page search palette can show site icons from Chrome's
favicon cache.)

**Are you using remote code?** No, I am not using remote code.

**Data usage**, what user data is collected: check **Web history** and **Website content**. (Volet reads tab titles,
addresses and last-use times, keeps archived tabs, and captures page previews for the tab switcher, all on the device. Chrome's policy counts local handling, so it's
disclosed even though nothing is transmitted.)

Certify all three:
- I do not sell or transfer user data to third parties, outside of the approved use cases.
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose.
- I do not use or transfer user data to determine creditworthiness or for lending purposes.

## Releasing an update

1. Bump `version` in `package.json` (Chrome refuses a package whose version isn't higher than the published one).
2. `pnpm check && pnpm test && pnpm test:e2e`
3. `pnpm zip`, which writes `output/volet-<version>-chrome.zip`.
4. Load `output/chrome-mv3` unpacked in a clean profile and try the main flows.
5. Dashboard, Package tab: upload the zip, update the listing if needed (`pnpm store:images` when the UI changed),
   then submit for review.
